# P4C4 Markbook — ESL Student Performance Tracker

A single-file web app for ESL teachers: weekly/monthly score entry for
Classroom Observations, Spelling, Daily Assignments and Tests, with live
averages, auto-grading (A*/A/B/C/D/U), per-student charts, and Excel
import/export in the SPR workbook format.

**No student data is stored in this repository.** All data stays in your
browser (localStorage). Load your class via "Import SPR Excel" and back it
up via "Download backup (JSON)".

Open the app: https://cdn.jsdelivr.net/gh/mdshezkhn/p4c4-markbook@main/index.html
