# SPR — Teacher Guide (FET & CET)

For everyday use by the Foreign English Teacher and the Chinese English
Teacher. SPR saves after every change — there is no save button to forget.

## Signing in
- Open the SPR link once on your computer; install it when the browser offers
  (it works offline afterwards).
- Your username and starting password come from the school administrator.
  Change the password at first sign-in (Profile → Change password).
- Forgot password → ask the administrator to reset; it expires in 30 minutes.

## The dashboard (both roles)
- **My classes** — the classes you teach, nothing else.
- **Enter assessments / Observations** — your daily work.
- **Import existing SPR** — bring your old Excel workbook in (checked first).
- **Review performance** — reports, RAG, semester comparison.

## FET — classroom observations
1. Open the class → the student list.
2. Tap the observation cell (skill + week) and pick the score; notes optional.
3. The cloud icon turns ✓ when the other teacher's computer can see it.
Observations are yours alone: the CET cannot change them, by design.

## CET — spelling tests, formal tests, daily assignments
1. Open the class → the assessment area.
2. Choose the test type and enter scores; invalid values are refused.
3. Missing entries stay empty (never zero): empty = not assessed yet.
Assessment scores are yours alone: the FET cannot change them, by design.

## When two teachers edit at once
The app keeps BOTH changes when they touch different things. If you both
change the same cell, the app shows both versions and asks which one to keep.
Nothing is ever silently thrown away, and the choice is recorded.

## Offline (school Wi-Fi drops)
- Keep working; a small "waiting to sync" badge shows unsent changes.
- When the internet returns, changes send automatically. Do not uninstall the
  app or clear browser data while the badge is showing.

## Importing your old SPR Excel
1. Dashboard → **Import existing SPR**.
2. Pick the file. It opens ON YOUR COMPUTER ONLY — nothing is uploaded.
3. SPR checks the workbook (broken totals, impossible scores, duplicates) and
   shows a traffic-light list: red = must fix in Excel first, amber = check,
   green = fine.
4. Download the audit report if you want a copy for records.
5. Import only happens when you press **Import now**; pressing Cancel changes
   nothing. Importing the same file twice does not double the students.

## Reports
- Student report and class reports (Review performance) always name the rules
  and the data they used — check the footnote line.
- RAG colours follow the school's existing grade boundaries; they flag where
  to look, they are not a judgement on a child.

## If something looks wrong
- "Cloud saving is paused" → the administrator has a 3-step fix; your data is
  safe on your computer meanwhile.
- Anything else: note what you tapped, tell the administrator.
