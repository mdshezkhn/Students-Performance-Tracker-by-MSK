# Final Manual Acceptance Checklist

For the school owner — no technical knowledge needed. Tick each box after
performing the step on the named device. Anything unticked = not yet
accepted. Total time ≈ 45 minutes with two teachers.

## A. Two-teacher live drill (two computers, two internet connections)
- [ ] Teacher A (FET) opens the app address and signs in with the account
      the administrator gave them.
- [ ] A sees the class (e.g. Primary 4A) and the student list.
- [ ] A records a classroom observation for one student and saves it.
      Message confirms it is saved/synchronised.
- [ ] Teacher B (CET), on a DIFFERENT computer and internet connection,
      signs in and opens the same class.
- [ ] B can SEE A's observation.
- [ ] B enters a spelling score, a test score and a daily assignment score.
- [ ] A refreshes: all three of B's scores are visible, and A's observation
      is still there unchanged.
- [ ] Both open the same student's report: figures match each other.
- [ ] A third teacher (not assigned to 4A) tries to open 4A: access denied.

## B. Offline behaviour (either teacher's computer)
- [ ] Turn off Wi-Fi / unplug the network.
- [ ] Enter one more score. The app says it is saved on this device.
- [ ] Close the browser COMPLETELY, reopen, open the app.
- [ ] The offline change is still there, marked as not yet synchronised.
- [ ] Turn the network back on; the change synchronises by itself.

## C. Excel round trip (either teacher's computer)
- [ ] Download the class SPR (Export).
- [ ] The file opens in Excel/WPS with all students and scores.
- [ ] Use "Import existing SPR" on the exported file: the audit finds
      no critical problems.
- [ ] Import is NOT applied without an explicit confirm step.

## D. Real mobile devices (physical phones)
- [ ] Android phone (Chrome): open the app, sign in, read one class,
      enter one observation or score. Page fits the screen; buttons tappable.
- [ ] iPhone (Safari): the same four steps.
- [ ] On the phone, turn on airplane mode, reopen the app: it still opens
      (offline), and one more entry made offline appears after airplane mode
      is switched off.

## E. Administrator checks (admin account)
- [ ] Create a test teacher account; sign in as them once; deactivate them;
      their sign-in now fails.
- [ ] Open Audit: today's actions by both teachers are listed with times.
- [ ] Download a backup; keep it in the school's safe storage.
